## Результат проверки по ключевым сценариям Task_4

**1.3 / 4.1. Гость и клиент не получают доступ к админке**
- Гость, открыв `#/admin` без авторизации, не видит админку, перенаправляется на страницу входа. Данные админки не отображаются. 
- Клиент с ролью `client`, открыв `#/admin`, получает 403-доступ (отказ в отображении админки). Прямой доступ к админ-API с токеном клиента возвращает 403. Запрос без токена — 401. Всё корректно.

**2.5. Конфликт записи на один слот ([два окна])**
- Клиент 1 выбирает свободный слот, доходит до подтверждения и подтверждает запись — успешно.
- Клиент 2 одновременно выбирает тот же слот и при подтверждении получает понятное сообщение: «Это время больше недоступно. Выберите другой слот.» 
- Список свободных слотов обновляется, занятый слот исчезает. Двойная запись не создана. Конфликт корректно предотвращён.

**3.2. Админ отменяет запись клиента ([два окна])**
- Админ во вкладке «Записи» отменил будущую запись клиента с указанием причины.
- У клиента запись в «Моих записях» получила пометку «запись отменена салоном», счётчик уведомлений увеличился. В уведомлении присутствуют название записи и причина отмены.
