Материалы
Чтобы вам было проще справиться с проектной работой, мы собрали материалы и инструменты, которые пригодятся на разных этапах создания сервиса.

Конспекты уроков
В конспектах собраны ключевые шаги по созданию сервиса. К ним можно вернуться, чтобы освежить в памяти нужную тему или уточнить порядок действий.

Конспект урока 5.1 «Прототипирование интерфейса сервиса записи (UX/UI)»(https://docs.google.com/document/d/1M5KbjUxlCqOZ1VTFXWBJSODbVlj-D8LzcAHfcDzuNvQ/edit?tab=t.0#heading=h.hf4z2lwa7kjp)
Конспект урока 5.2 «Настройка проекта: Git и GitHub»(https://docs.google.com/document/d/1imCCbeu2tF6oTrHLzqGfqp86iS8l_1Agx_HPNj91DD8/edit?tab=t.0#heading=h.mj4qb587cuxv)
Конспект урока 5.3 «Настройка backend-проекта и базы данных»(https://docs.google.com/document/d/1aijhOVvrCcW_HTNpNiFgW2BmzCQofJPdGm5ybKoZGIk/edit?tab=t.0#heading=h.moc2nsh9nquv)
Конспект урока 5.5 «Админ-панель и тестирование»(https://docs.google.com/document/d/1t4HKyq-f9f2nVCf19lvqYoSLKcKsKLYv8iwtPmTRZEI/edit?tab=t.0#heading=h.moc2nsh9nquv)
Шаблон паспорта продукта
Шаблон поможет описать назначение сервиса, его аудиторию, роли пользователей, основные сценарии, функции, ограничения и возможные риски. Заполните его на первом этапе и сохраните в файле
CLAUDE.md
 или
AGENTS.md
 в папке проекта.

Шаблон паспорта продукта(https://docs.google.com/document/d/18bX9aYMYAOYimrLvLVXQ2oJepia9-8qLZ8vzSN78aS4/edit?tab=t.i6b0k8kv9qn5#heading=h.co1bbqk6on8q)


Шаблон дневника сборки сервиса записи
В дневнике сборки нужно фиксировать ключевые промпты, принятые решения, результаты проверок и возникшие проблемы. Заполняйте его постепенно во время работы над всеми этапами проекта.
Шаблон дневника сборки сервиса записи (https://docs.google.com/spreadsheets/d/1Mrh94Y8cxRaYKsLsMLm6gArqlfsbrPaOFrzPCiMgDWs/edit?gid=622241638#gid=622241638)


Техническое задание на создание сервиса записи для бьюти-студии «Ноготочки»
В техническом задании собрана информация о студии «Ноготочки», ее услугах, мастерах, расписании и правилах записи. Передайте файл ИИ-ассистенту и используйте его как основу при разработке сервиса. Если вы работаете над собственным кейсом, замените исходные данные на свои.

Техническое задание на создание сервиса записи для бьюти-студии «Ноготочки» (https://docs.google.com/document/d/1b_k5wRirgX0owa2saIDYnaX2S-vJfC3dhXefvog8XQ8/edit?tab=t.0#heading=h.tc17gyshin5d)


Шаблон отчета о тестировании
Шаблон поможет подготовить сценарии для проверки полного пути сервиса. Добавьте в него ожидаемые результаты, пройдите каждый сценарий и зафиксируйте, что произошло на самом деле.

Шаблон отчета о тестировании (https://docs.google.com/document/d/1CaHCUlA8LYmoGHMrnETbOpIYTIBSkWUAD71lI3M8-Ws/edit?tab=t.jke6r01al1e6#heading=h.ufrgx4yq1ue8)


Шаблон отчета о публикации сервиса
Шаблон пригодится, если вы решите выполнить расширенный уровень и опубликовать сервис. Он поможет зафиксировать результаты проверки опубликованной версии: работу домена и HTTPS, ключевые сценарии, вход через Яндекс, найденную поломку и решение по работе с персональными данными.

Шаблон отчета о публикации сервиса (https://docs.google.com/document/d/1MiI7hPQZ_0grn62-9z_Kgj5593DVQmLXjLUYsv5XAXw/edit?tab=t.0#heading=h.mjolz7pr4qut)


Памятка: как подготовить сервис к реальному запуску
Памятка поможет проверить проект перед запуском для реальных пользователей. Она предназначена для тех, кто захочет продолжить работу над сервисом после завершения курса, и не относится к обязательной части проектной работы.

Памятка: как подготовить сервис к реальному запуску (https://drive.google.com/file/d/11UsyZBmPG9atkBBjSba0qSkEifBKwX0c/view)


Инструменты
Для выполнения базовой части проектной работы вам понадобятся:

Claude в режиме Claude Code — для сборки и доработки сервиса.
Редактор прототипов, который вы использовали в модуле, — для проектирования экранов.
Браузер с режимом инкогнито — для проверки сервиса под разными пользователями.
GitHub или облачное хранилище — для передачи проекта на проверку.
Если вы выполняете расширенный уровень, дополнительно понадобятся сервер для публикации сервиса и домен.
